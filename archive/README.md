# Archived Code and Configurations

This directory contains code that has been archived for reference purposes but is no longer part of the active codebase.

## Python Backend

The `python_backend` directory contains an alternative Flask implementation of the backend. This was created as an option but is not actively maintained in favor of the Node.js Express backend.

## Python Workflow

The `python_workflow.json` file contains the workflow configuration for the Python backend.

## When to Use

This code could be useful if:

1. There's a need to deploy to a Python-friendly environment in the future
2. You want to reference the API implementations for documentation or testing purposes
3. You decide to switch back to a Python-based solution

Note that this code is provided as-is and may not be compatible with the latest version of the application.
